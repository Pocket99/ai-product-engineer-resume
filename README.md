## 代表产品

### 咪咪咪｜AI 桌面养成游戏

独立开发 · 2026.08 起 · [产品官网](https://mimimi.ziruiqiu.com/)

- **角色对白与剧情。** 用 DeepSeek 根据当前场景、玩家选择和近期对话生成角色回复。模型以结构化格式建议角色关系如何变化，由 Rust 规则层校验后推进剧情。奖励结算时按命令去重，避免重试导致重复发奖。
- **玩家记忆。** 玩家可逐条确认、修改或删除角色记住的事。存档保存在本地 SQLite 中，写入前校验记忆版本，防止延迟返回的模型回复把已删除的记忆写回来。
- **定价与成本。** 将基础养成与按需付费的 AI 对白分开，点数用完仍可继续基础游戏。Python 服务在调用模型前预留费用，返回后按实际 token 用量结算，并设置日、月预算。
- **跨平台发布。** 用 React、Pixi.js 和 Tauri 开发桌面客户端，在持续集成中测试对话、存档和安装包。官网已开放 Windows x64 与 Apple Silicon Mac 测试版的购买和下载。

YCH-YOYO｜电商运营 MCP 服务

平台全栈负责人 · 2026.10 上线 · Python / Flask / Model Context Protocol · 产品官网

  • 工具设计。 将销售统计、订单查询、商品维护和图片管理封装为 9 个工具。MCP 客户端通过 Streamable HTTP 连接，按凭据权限发现可用工具。服务端在每次调用时校验权限和参数，保留脱敏审计记录。
  • 写操作。 商品更新同时校验调用方的确认标记和商品版本。运营人员在后台改过商品后，Agent 基于旧版本的更新会收到冲突提示；超时后以相同操作 ID 和参数重试，可取回原结果，避免重复创建商品或上传图片。
  • 上线验证。 使用官方 Python MCP SDK 在生产环境完成连接、发现 9 个已授权工具并执行只读业务查询。用自动化测试覆盖商品更新冲突、进程中断后的恢复和重复写入。

Jarvis-AI｜Coding Agent 会话服务

开源项目个人分支 · 2026.09 · Python / FastAPI / WebSocket · 本人提交与测试

  • 会话接续。 在现有 Agent 上实现本地会话服务，让命令行和网页读写同一份对话历史。用户可以在命令行开始任务，再从网页接续；下一轮切换模型时仍保留之前的上下文。
  • 工具执行。 通过 WebSocket 推送工具调用和执行结果。模型请求执行终端命令时，服务暂停并等待用户批准；用户拒绝或连接中断时，待审批命令不执行。等待审批期间拒绝并发任务，避免两项操作交错。
  • 失败恢复。 只保存成功完成的轮次，失败后可从上一次有效会话继续。为会话服务编写 10 项自动化测试，覆盖逐轮切换模型、跨端恢复、审批拒绝、并发和失败后重试。

咪咪咪｜有长期记忆的角色对话 Agent

独立开发 · 2026.08 起 · Python / DeepSeek / Rust / SQLite · 产品官网

  • 上下文与动作。 每轮按当前活动、玩家选择、近期对话和已授权记忆组装请求，并告诉模型此时可用的动作。模型返回对白及结构化建议；规则层根据已发生的事件和当前权限校验关系变化与剧情推进，再更新本地存档。
  • 记忆与回顾。 玩家可逐条确认、编辑或删除长期记忆。请求绑定上下文和记忆版本，旧回复晚到也无法恢复已删内容。生成活动回顾时要求模型引用原对话，并校验引用，避免将虚构情节写入回顾。
  • 提示词优化。 将回复需要的 JSON Schema 约束编译为紧凑说明，并以往返测试验证约束等价。用 DeepSeek 离线分词器测试 3 个合成场景，在保留玩家历史、记忆与权限信息的前提下，单轮输入 token 减少 36.4%–39.1%。其中校园场景由 8,461 降至 5,153。
  • 行为评估。 设计 16 个合成场景，逐一检查两种对话协议的请求装配；选取其中 5 个，用真实模型对比新旧提示词。根据回复中虚构玩家动作、忽略角色体力等问题修订提示词，再用模型自己的上一轮回答验证多轮续接。
  • 计量与重试。 分开记录玩家点数和供应商 token 成本。调用前预留，成功后结算，失败释放玩家点数；供应商成本不明时单独保留待核对记录。同一操作重试时复用已完成结果，避免二次调用和扣点。
